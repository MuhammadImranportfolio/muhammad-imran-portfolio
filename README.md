# Muhammad Imran — Personal Portfolio

A responsive personal portfolio website for Muhammad Imran, Biotechnology Researcher.

## Features

- Responsive layout for desktop, tablet, and mobile
- Research-focused personal branding
- Sections for research, projects, education, skills, achievements, and contact
- No framework required
- Compatible with GitHub Pages

## How to use

1. Create a GitHub repository named `muhammad-imran-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Replace `your-email@example.com` in `index.html` with your actual email.
4. Open your GitHub repository.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, select:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
7. Save and wait for GitHub Pages to publish the website.

## Personalization

You can add:
- A professional profile photograph
- Your CV PDF
- Research publications
- ORCID profile
- Google Scholar profile
- Research project images
- A custom domain
